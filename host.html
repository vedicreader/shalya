host

The application an agent works inside, and how it says what it can do.

Saying what a host can do

Each kind of support is a capability group, named by a short string such as 'code', 'web' or 'shell'. A capability class names one group and lists the methods its tools need as abstract methods. A host declares a group by inheriting the class. Python’s ABC machinery then refuses to create an instance of a host that inherits a capability class without writing all of its methods, so a host cannot claim a group it only half supports.

provides returns the groups a host’s classes declare, minus the instance’s without set. without covers groups this particular instance cannot serve even though its class can, for example because web access was switched off or the fossick package is not installed. can(group) asks about one group. tools_for in shalya.tools uses provides to decide which tools a host gets.

Capability

def Capability(
    *args, **kwargs
):

One capability group. A host declares the group by inheriting the class that names it.

Host is the base class of every host. The folder boundary is not a capability group of its own, because every tool needs it: roots (the open folders), check (resolve a path and refuse it if it falls outside them), walk, read, write and text_at are abstract methods of Host itself, and every host provides the file group. add_root, close, approvals and note have defaults a host may override.

Two attributes let an application screen what reaches the model. read_guard is described in shalya.core, and model_local is the function that tells it which model the turn uses. writes = False marks a host that cannot write, which gets no write tools.

The groups

Each class below names one group and the methods its tools call. Methods with a body are optional and have a default; abstract ones must be written by any host that declares the group.

Notebook tools list cells by id and then edit a cell by sending its id back, so ids must not change between two reads. fastcore’s read_nb invents a random id for each cell saved without one, which would break that. nb_read is the notebook reader every host uses instead. It gives cells without ids stable ones based on their position: c0, c1 and so on.

CodeHost

def CodeHost(
    *args, **kwargs
):

Code search and structure.

The session and shell groups have contracts the tools rely on but cannot check, so a host must keep them:

  • run_python may read anything in the user’s live namespace and bind its results to new names, but never rebinds or deletes a name the user made. The agent is told this, and the host enforces it.
  • inspect_python runs code without changing the user’s names, in one of two scopes. isolated, the default, runs on a copy of the namespace in a sandbox that allows attribute reads and builtins and refuses most library method calls, so it needs no trust. overlay runs in the real interpreter against the real namespace, under rules that let the agent bind names in its own layer but never delete, rebind or change the user’s. list(df.columns) works in overlay and not in isolated. A host may refuse overlay, and scopes says which scopes it honours.
  • run_cmd resolves cwd through check. Confining the working directory does not confine what the command does, which is why the run_shell tool counts as a write and goes to a person for approval. Standard output and standard error come back together in one string, in the order they were written. timeout is enforced by killing the command’s whole process group. A failing command returns a non-zero exit code; it does not raise.

There are eleven groups. The group name in each class is the key tools_for looks up, so the class and the toolset must agree on it, or the group’s tools never appear and nothing reports why. The test below pins the names.

GROUP_CLASSES = (CodeHost, WebHost, BrowserHost, NotebookHost, MemoryHost, AskHost, WatchHost, SessionHost,
                 ShellHost, ApiHost, GitHost)
sorted(c.group for c in GROUP_CLASSES)
test_eq(sorted(c.group for c in GROUP_CLASSES),
        ['api', 'ask', 'browser', 'code', 'git', 'memory', 'notebook', 'session', 'shell', 'watch', 'web'])
assert all(issubclass(c, Capability) for c in GROUP_CLASSES)
test_eq(Capability.group, '')                             # the base names no group
test_eq(Host.group, 'file')                               # and the path boundary is its own
test_eq(len({c.group for c in GROUP_CLASSES}), len(GROUP_CLASSES))   # no two share a name

provides is the only way the toolset asks what a host supports. This example host declares the code and web groups, but its without removes web, as if fossick were not installed.

class Demo(Host, CodeHost, WebHost):
    without = {'web'}                                    # fossick is not installed here
    @property
    def roots(self): return ['/proj']
    def check(self, path, must_exist=False, reading=False): return Path('/proj')/path
    def walk(self): return []
    def read(self, path): return None
    def write(self, path, text): return str(path)
    def text_at(self, path): return ''
    def search(self, query, limit=20): return [Hit('/proj/a.py', 1, 'a', 'def a(): ...')]
    def symbols(self, path): return []
    def peers(self, path, line, limit=20): return []
    def public_api(self, package, limit=MAX_API): return []
    def web_search(self, query, n=20): return []
    def read_url(self, url, remember=True): return None
    def research(self, query): return ''

d = Demo()
sorted(d.provides), d.can('code'), d.can('web')
test_eq(sorted(d.provides), ['code', 'file'])   # every host has the file group
test_eq(d.can('code'), True)
test_eq(d.can('web'), False)
test_eq(d.can('memory'), False)

A host over real folders

LocalHost is the reference host. It works on folders on the local machine and declares every group except browser. A group whose backend is missing is put in without: web when web access is off or fossick is not installed, memory, ask and watch when no vault is given, and api when no API backend is given. A kernel can be attached later without building a new host.

SKIP_DIRS and SKIP_SUFFIXES name what a walk or a grep leaves out: version-control folders, virtual environments, caches, build output, and binary files such as images, archives and model weights. They are not part of the project, and reading them would waste the model’s context.

assert {'.git', '.venv', '__pycache__', 'node_modules'} <= SKIP_DIRS
assert {'.pyc', '.so', '.png', '.gguf'} <= SKIP_SUFFIXES
assert MAX_VARS > 0 and LD_CHARS > 0

These are the constructor’s arguments. roots are the folders the agent may read and write, and read_roots folders it may only read. With index=True, the default, the host starts indexing every open folder with kosha in a background thread, and search uses ripgrep until that index is ready. web, memory, apis and kernel attach the optional backends. read_outside=True lets read tools open any file on the machine except credential files. without is computed once, from these arguments and the packages installed.

def LocalHost(

    ns:NoneType=None, # live namespace; fresh dict when None
    approvals:NoneType=None, # write approval handler

LocalHost.add_root

def add_root(
    path, readonly:bool=False, # open it for reads only: searched, never written
):

Open an existing folder for reads and writes, or for reads only. Never creates one.

add_root opens another existing folder, for reads and writes or, with readonly=True, for reads only, and starts indexing it. It never creates a folder. Open folders never overlap: a folder inside one already open is not opened again, and opening a parent closes the folders inside it.

extra = Path(tempfile.mkdtemp()).resolve()/'extra'
(extra/'sub').mkdir(parents=True)
(extra/'notes.md').write_text('read me\n')
local.add_root(str(extra)), local.added_roots
test_eq(local.added_roots, [str(extra)])
test_eq(local.roots[-1], str(extra))                     # the new root is open for reads and writes
test_eq(local.add_root(str(extra)), str(extra))          # already open: no second entry
test_eq(len(local.added_roots), 1)
test_eq(local.add_root(str(extra/'sub')), str(extra))    # inside an open root: nothing to open
test_eq(local.added_roots, [str(extra)])
test_fail(lambda: local.add_root(str(extra/'nope')), contains='no such folder')
test_fail(lambda: local.add_root(str(extra/'notes.md')), contains='not a folder')
parent = Path(tempfile.mkdtemp()).resolve()/'parent'
(parent/'child').mkdir(parents=True)
nest = LocalHost(roots=[str(parent/'child')], index=False)
test_eq(nest.add_root(str(parent)), str(parent))
test_eq(nest.roots, [str(parent)])                       # opening a parent closes the root inside it
test_eq([r for r in nest._pending if r not in nest.roots], [])   # and nothing waits on a closed one

def note(
    text

note tells the user something without waiting for an answer, such as “starting a kernel”. It adds the message to transcript, then calls the status callback given to the constructor, if any. A callback that raises is ignored, so a broken display cannot end an agent’s turn.

Searching the code

Three engines can answer a search. Kosha’s index combines keyword and vector search once it has synced. Ripgrep finds literal matches while the index is still building. If neither is installed, the host reads the files itself. Which engine answered is reported to the model with the results.

LocalHost.sync_index

def sync_index(
    wait:bool=False, force:bool=False
):

Run Kosha.sync for every open root, once, in a daemon thread. Each root publishes as it returns.

sync_index starts one background thread that runs Kosha.sync for each open folder in turn. Each folder’s index becomes searchable as soon as its own sync finishes. Calling it again while the thread is running does nothing, and wait=True blocks until it is done.

test_eq(quiet._index_thread.name, 'shalya-kosha-sync')

path_scope

def path_scope(
    pf, root
):

path_filter as a regex over paths relative to root: '' filters nothing, None when it names a place outside root.

path_scope reads a path_filter as a model writes one. A folder or file under the root, named relative to it, absolute, or starting with the root’s own name, matches that place and what is below it. Anything else is a substring of the relative path, in any case, and * and ? work as in a glob. An absolute path outside the root returns None, so grep skips that root.

tree = Path(tempfile.mkdtemp()).resolve()
(tree/'pkg'/'sub').mkdir(parents=True); (tree/'pkg'/'sub'/'mod.py').write_text('x')
test_eq(path_scope('', tree), '')
test_eq(path_scope(str(tree), tree), '')
assert path_scope('/elsewhere/pkg', tree) is None
assert re.search(path_scope('pkg/sub/', tree), 'pkg/sub/mod.py') and not re.search(path_scope('pkg/sub', tree), 'xpkg/sub2/a.py')
assert re.search(path_scope(f'{tree.name}/pkg', tree), 'pkg/sub/mod.py')
assert re.search(path_scope('MOD', tree), 'pkg/sub/mod.py') and re.search(path_scope('*.py', tree), 'pkg/sub/mod.py')

LocalHost.search

def search(
    query, limit:int=20
):

The code index and the literal scan, fused by rank rather than tried in order.

search runs kosha’s index and ripgrep together and merges their hits by rank with reciprocal rank fusion, so a hit both engines find rises to the top. If neither returns anything and ripgrep is not installed, it falls back to reading the files. An empty query returns [], not everything.

Reading one page

read_page(fossick, url) turns one URL into markdown, and LocalHost.read_url calls it. It takes the fossick module as an argument, so a host with web access switched off never imports it, and code outside a host can use it too. It returns None, or a record with text, url, title, kind (page, paper or repo), sections and the strategy that produced the text.

It works in stages. A URL that has a dedicated reader in fossick, such as an arXiv paper, a GitHub file, a YouTube video or a PDF, is read with it. Anything else is fetched. Several extraction methods then compete to find the article in the fetched page: readability, each of the wrappers in CONTENT_SEL, and a selector for headings, paragraphs and lists inside the main area. The longest result wins, reduced by its share of bullet lines, since a page that is mostly bullets is a navigation column. A result shorter than THIN_PAGE characters probably means the site answered with an empty shell that builds the page with JavaScript, so the page is fetched again with a real browser and then in stealth mode. Repeated <article> elements, as on a feed or digest page, are also returned separately in sections, and the page’s JSON-LD goes on top. sel names a CSS selector to try before any guess.

Memory, watches and API specifications

The memory, ask and watch groups are served by a vishalakshi Vault, opened by whatever built the host and passed in as memory. A vault stores pages and notes as documents divided into sections. Each host method forwards to one vault method: memory_search to search, memory_tree to toc, memory_read to read, memory_topics to topic_tree, memory_forget to forget and remember to note, while ask, watch, watches, unwatch and poll keep their names. Without a vault each of them raises an error saying there is no vault.

class Specs:
    "An api backend over fastspec: it reads the spec, and httpx makes the call."
    def __init__(self): self.parsed, self.base = {}, {}

    def api_load(self, src, name=''):
        spec = src if isinstance(src, dict) else json.loads(Path(src).read_text())
        p = SpecParser.from_openapi(AttrDict(spec))
        key = name or (spec.get('info') or {}).get('title') or 'api'
        self.parsed[key] = p
        self.base[key] = ((spec.get('servers') or [{}])[0].get('url') or '').rstrip('/')
        return {'name': key, 'operations': len(p.ops), 'groups': sorted({o.group or '' for o in p.ops})}

    def _rows(self, group='', name='', match=''):
        ops = self.parsed[name].ops if name else next(iter(self.parsed.values())).ops
        return [{'name': o.name, 'group': o.group or '', 'verb': o.verb, 'path': o.path, 'summary': o.summary or ''}
                for o in ops if (not group or o.group == group) and (not match or match in o.name)]

    def api_ops(self, group='', name='', match='', limit=None, offset=0):
        rows = self._rows(group, name, match)
        return rows[offset:] if not limit else rows[offset:offset + int(limit)]

    def api_count(self, group='', name='', match=''): return len(self._rows(group, name, match))

    def api_call(self, operation, name='', **params):
        key = name or next(iter(self.parsed))
        op = next(o for o in self.parsed[key].ops if o.name == operation)
        path = op.path.format(**{k: params.pop(k) for k in list(params) if f'{{{k}}}' in op.path})
        r = httpx.request(op.verb, self.base[key] + path, params=params, timeout=30)
        return {'status': r.status_code, 'body': r.text[:200]}

Attaching a kernel to an existing host

When kernel is set, run_python, inspect_python, list_vars, restart_kernel, scopes and kernel_kind go to the kernel instead of the in-process namespace. The example shows the shape a kernel must have. Assigning one to an existing host keeps its groups and backends.

class Kernel:
    "The shape `LocalHost` expects of a kernel: four calls and two facts, and a `restart` if it can."
    scopes, kind = ('isolated', 'overlay'), 'ipykernel'
    def __init__(self): self.ns = {}
    def run(self, code): exec(code, self.ns); return 'ran on the kernel'
    def inspect(self, code, scope='isolated'): return f'inspected under {scope}'
    def list_vars(self): return ', '.join(k for k in self.ns if not k.startswith('__'))
    def restart(self): self.ns.clear(); return 'restarted on the kernel'

k = LocalHost([root], index=False)
before = sorted(k.provides)
k.kernel = Kernel()
before, sorted(k.provides), k.scopes, k.kernel_kind
test_eq(sorted(k.provides), before)                 # attaching a kernel takes nothing away
test_eq(k.scopes, ('isolated', 'overlay'))
test_eq(k.kernel_kind, 'ipykernel')
test_eq(k.run_python('answer = 42'), 'ran on the kernel')
test_eq(k.list_vars(), 'answer')
test_eq(k.inspect_python('answer', 'overlay'), 'inspected under overlay')
test_eq((k.restart_kernel(), k.list_vars()), ('restarted on the kernel', ''))
del Kernel.restart
test_fail(k.restart_kernel, contains='cannot be restarted')   # a kernel without `restart` refuses rather than pretending

A dhrishti AgentSession provides the protected overlay scope. This adapter wraps one as a kernel.

from dhrishti.agent import AgentSession
class DhrishtiKernel:
    scopes, kind = ('isolated', 'overlay'), 'dhrishti'
    def __init__(self, owner): self.session = AgentSession(owner=lambda: owner, rules=[], log=False)
    def _text(self, result):
        if not result.ok: return result.error
        value = getattr(result.result, 'value', None)
        return (result.stdout + (str(value) if value is not None else '')).strip() or '(no output)'
    def run(self, code): return self._text(self.session.run(code, 'overlay'))
    def inspect(self, code, scope='isolated'): return self._text(self.session.run(code, scope))
    def list_vars(self): return '\n'.join(f'{x.name} {x.type} {x.value}' for x in self.session.snapshot())

import time
if shutil.which('tmux'):
    import fastmux
    sess = fastmux.new_session(name=f'shalya-test-{uuid.uuid4().hex[:6]}', width=140, height=40, cwd='.')
    try:
        me = list(list(sess.windows)[0].panes)[0]
        user = me.split('right', cwd='.')
        h = LocalHost(['.'], index=False, tmux=me)
        user.send('echo hello-from-user'); user.send_keys('Enter', wait_ms=2000)
        tt = h.terminal_text(50)
        assert tt.startswith(f'## pane {user.id}') and 'hello-from-user' in tt, tt
        rid = h.run_cmd_bg("printf 'a\\nb\\n'; sleep 30"); time.sleep(1)
        st, txt = h.cmd_output(rid, 0); assert st == 'running' and txt.startswith('a\nb'), (st, txt)
        assert h.cmd_stop(rid) == 'stopped' and h.cmd_output(rid, 0) == ('stopped', txt)
        rid2 = h.run_cmd_bg('exit 3'); time.sleep(1.5); assert h.cmd_output(rid2)[0] == 'exit 3'
        pid = h.open_pane('tail -f /dev/null', title='watch'); assert pid.startswith('%')
        e = h.environment(); assert e.endswith(f'pane {me.id}'), e
        h.close()
        ids = {p.id for w in sess.windows for p in w.panes}
        assert ids == {me.id, user.id}, ids
    finally: sess.kill()
