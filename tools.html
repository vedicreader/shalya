tools

Every tool an agent can be given, and how to pick the ones a host can support.

Every factory takes mx, the largest number of characters one tool result may hold, because the model in use sets that budget. Results longer than mx are clipped with the helpers in shalya.core.

A tool must never raise, since an exception would end the agent’s turn. resolved checks a path against the host and returns (path, ''), or (None, error) with an ERROR: message the tool can return as is. readable resolves a path a tool is only going to read, which lets a host with read_outside allow reads beyond its open folders.

Searching the code

code_tools builds the tools for finding code. search_code searches the open folders and the installed packages, by meaning when kosha’s index is ready and literally until then. grep finds exact lines matching a pattern, ls lists a folder, and outline lists the functions and classes in one file. When the host has an index, two more appear: similar_code, which finds code like the function at a given line, and public_api, which lists a package’s public names.

A search can return hits the agent cannot open, for example in an installed package outside the open folders. reach_hint adds a line under each hit saying which tools can reach that path. screen_hits passes hits through the host’s read_guard, asking once per file.

A search covers installed packages, but the read and write tools may refuse a path outside the open folders. Each hit’s hint names only the tools that can reach it on this host: view and edit inside the open folders, view only in a read-only folder or with read_outside, and neither anywhere else.

from shalya.core import Hit
lib = Path(tempfile.mkdtemp()).resolve()/'site-packages'; lib.mkdir()
(lib/'sizes.py').write_text('def threshold(n): return n\n')
class Spread(LocalHost):
    def search(self, query, limit=8): return [Hit(str(root/'pkg'/'sizes.py'), 1, 'threshold'), Hit(str(lib/'sizes.py'), 1, 'threshold')]
def hints(**kw):
    "The hint under each hit, for a host built with `kw`."
    sc = {t.__name__: t for t in code_tools(Spread([root], index=False, **kw))}['search_code']
    return sc('threshold').split('\n')[2::2]   # note, then a hit line and its hint, per hit
mine, theirs = hints()
assert 'view_file/replace_text' in mine, mine
assert 'view_file' not in theirs and 'outside the open folders' in theirs, theirs     # nothing here can read it
for kw in (dict(read_outside=True), dict(read_roots=[lib])):
    mine, theirs = hints(**kw)
    assert 'view_file/replace_text' in mine and 'view_file' in theirs and 'replace_text' not in theirs, (kw, theirs)   # readable, never written

Files

file_tools builds the tools for reading and editing files. view_file shows a file as lineno|hash|content lines, where the hash is a short fingerprint of the line, and a picture comes back as an image. replace_text edits a file with a list of {oldText, newText} pairs: each oldText must match the file exactly once, and either every edit applies or none does. create_file writes a whole file, and add_root opens another folder. A host that cannot write gets only view_file.

exhash_tools builds edit_file, an editor that addresses lines by the lineno|hash| prefixes view_file shows and refuses an edit when the line has changed since it was viewed. It is opt-in: ask for it with tools_for(host, optin=('exhash',)).

A host’s read_guard sees what each read tool would send, and its answer is what the model gets: the text, a masked version of it, or a refusal. Search hits are checked once per file.

assert '[EMAIL]' in ft['view_file'](str(cp)) and 'ada@x.org' not in ct['grep']('ada@x')
test_eq(ft['view_file'](str(root/'pkg'/'sizes.py')), f"ERROR: withheld: {root/'pkg'/'sizes.py'}: Local only")
host.read_guard = None
assert 'ada@x.org' in ft['view_file'](str(cp))

Notebooks

notebook_tools builds the notebook tools, which address cells by id, never by line. notebook_cells lists a notebook’s cells with their ids, view_cell shows one cell’s source with line numbers, edit_cell edits a cell with the same {oldText, newText} pairs as replace_text, and add_cell inserts a new cell.

notebook_tools

# every write consults the host's optional guard
class Guarded(Host):
    group = 'file'
    def __init__(self): self.seen = []
    @property
    def roots(self): return ['/proj']
    def check(self, path, must_exist=False, reading=False): return Path('/proj')/path
    def check_write(self, p): self.seen.append(str(p)); raise HostError('generated')
    def walk(self): return []
    def read(self, path): return 'x = 1\n'
    def write(self, path, text): raise AssertionError(f'the guard was bypassed for {path}')
    def text_at(self, path): return ''
g = Guarded()
guarded = {t.__name__: t for t in file_tools(g) + exhash_tools(g) + notebook_tools(g)}
for nm, args in (('replace_text', ('a.py', [{'oldText': 'x = 1', 'newText': 'x = 2'}])), ('edit_file', ('a.py', [['1|ab|', 'd']])),
                 ('create_file', ('a.py', 'whole file')), ('add_cell', ('a.ipynb', 'y = 2')),
                 ('edit_cell', ('a.ipynb', 'c1', [{'oldText': 'x', 'newText': 'y'}]))):

The web, and what was read before

The web tools and the memory tools are separate groups, and the difference matters. web_tools goes to the network now: web_search returns titles and URLs, and read_url reads one page as text and asks the host to keep it in memory unless remember=False. Memory

memory_tools builds the tools over the host’s vault. memory_search searches remembered pages and returns matching sections with their headings, age and whether they are stale. memory_read browses: with no argument it lists every document, with a document id or title it shows its headings, and with a section id such as doc#3 it returns that section. remember files a note, and a later note with the same key replaces it. memory_forget deletes a document, and only at the user’s request.

lesson_text

def lesson_text(
    text, # the lesson: what to do the next time the cue fires
    cue:str='', # the shape of situation the lesson applies to
    component:str='', # the part of the harness it concerns, one of `LESSON_COMPONENTS`
    evidence:str='', # what in the conversation shows it
    confidence:str='', # one of `LESSON_CONFIDENCE`
):

Format a lesson for remember: text alone, or one field: value line per filled field, lesson first.

An agent can use remember to record a lesson learned from a mistake, with four extra fields: cue (the kind of situation it applies to), component (the part of the harness it concerns, one of LESSON_COMPONENTS), evidence and confidence (one of LESSON_CONFIDENCE). lesson_text formats such a note as one field: value line per filled field, starting with lesson, so a vault titles the note by its first line. Line breaks inside a value become spaces and empty fields are left out. Without any of the four fields, the text is stored unchanged. An unknown component or confidence, or extra fields with an empty text, raise a ValueError, which remember returns as an ERROR: result.

print(lesson_text('filter on the root-relative path', cue='an empty filtered search', component='tool', confidence='high'))

watch_tools builds the watch tools. ask_tools

def ask_tools(
    host, mx:int=6000
):

The ask_memory tool, which answers a question from remembered research with citations.

These checks use a stand-in memory backend with fixed answers, to test JSON output, citations, watch listings, errors and the write marks. The host notebook tests the real vault.

class MemoryResults:
    watch_actions = ('url', 'remind', 'web', 'folder')
    def memory_search(self, query, limit=8):
        if query == 'fail': raise RuntimeError('vault unavailable')
        return [{'id': 'd1', 'title': 'Kettles', 'text': 'boils at 100C', 'age': 60, 'stale': False}][:limit]
    def memory_tree(self, document=''):
        roots = [{'id': 'd1', 'title': 'Kettles'}]
        return roots if not document else [roots[0] | {'children': [{'id': 'd1#2', 'title': 'Boiling'}]}]
    def memory_read(self, node_id): return {'id': node_id, 'text': 'boils at 100C'}
    def memory_forget(self, doc_id): return doc_id == 'd1'
    def remember(self, text, title=None, tags=(), key=''):
        self.key, self.text = key, text
        return {'doc_id': 'd2', 'title': title or text, 'replaced': bool(key)}
    def watch(self, target, action='remind', every='1d', note=None, **params):
        self.watched = (target, action, every, note, params)
        return {'id': 'w1', 'kind': action, 'action': action, 'target': target, 'every': 86400, 'runs': 0}
    def watches(self, due_only=False):
        return [] if due_only else [{'id': 'w1', 'target': 'renew domain', 'kind': 'remind', 'action': 'remind',
                                     'every': 86400, 'runs': 0, 'last_status': None}]
    def unwatch(self, watch_id): return watch_id == 'w1'
    def poll(self):
        return {'ran': 1, 'checked': 1,
                'results': [{'status': 'ok', 'action': 'remind', 'target': 'renew domain'}]}
    def ask(self, question, ref=None, instruction=''):
        return {'answer': 'Water boils at 100C.', 'policy': 'redact',
                'pii': {'has_pii': question == 'who', 'identifying': {'name': 1}},
                'cited': [{'n': 1, 'breadcrumb': 'Kettles', 'node_id': 'd1'}]}

git_tools builds the git tools on top of gheasy. The read tools are git_status, git_divergence (how the branch differs from another, with the outcome of a fast-forward, merge, rebase or reset worked out in advance), git_diff and git_log. Which tools a host gets

What a sub-agent may have

A sub-agent that only looks things up should not change anything. read_only(tools) returns the tools it may have. Every write tool is removed, unless the tool provides a read-only version of itself in its read_only attribute, which is then used instead. writes=True keeps the write tools. block removes tools by name. max_calls puts the result behind a hard budget: once the sub-agent has made that many calls in total, every tool answers that the budget is spent.

The browser

The browser group is a tab the agent drives. Looking at a page (browse, screenshot, page_text, page_reload) acts without writing. Acting on it (page_click, page_type, page_eval) counts as a write and goes to a person. A screenshot comes back as Media: text naming the saved file, carrying the picture for an agent loop that can send it to the model. The example uses a stand-in browser host.

class Tab(Host, BrowserHost):
    "A browser host over a dict of pages."
    roots, check, walk, read, write, text_at = (), None, None, None, None, None
    def __init__(self): self.seen = []
    def browse(self, url): self.seen.append(('browse', url)); return f'p1 Example'
    def screenshot(self, page=''): return '/tmp/p1.png'
    def page_text(self, page=''): return '# Example'
    def page_reload(self, page=''): return 'Example'
    def page_click(self, page, x, y): self.seen.append(('click', page, x, y)); return 'clicked'
    def page_type(self, page, text): return 'typed'
    def page_eval(self, page, js): raise ValueError('refused on this origin')
tab = Tab()
assert not any(group_of(t.__name__) == 'browser' for t in tools_for(tab)), 'opt-in: a host that can browse still offers nothing unasked'
bt = {t.__name__: t for t in tools_for(tab, optin=('browser',))}
test_eq(OPTIN['browser'](LocalHost([Path('.')], index=False, web=False)), [])   # named for a host without the group: nothing
